# Use explicit allocation cycles and atomic group placement

Each office defines allocation cycles with attendance dates, an intent cutoff
and processing time, handling late changes incrementally. Group placements and
required linked parking remain consistent, with the completed, validated plan
published together as defined by the
[two-phase allocation decision](0037-form-collaborator-groups-before-packing-desk-allocations.md).
Intermediate work remains a proposal; relevant changes require revalidation and
repair before publication, preserving previously published bookings.

Ordinary direct desk booking opens after the date's main plan is published. Before
then, requests enter intent collection so the cohort can be planned together.
