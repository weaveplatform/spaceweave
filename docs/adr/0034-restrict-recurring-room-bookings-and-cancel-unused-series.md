# Superseded: app-specific recurring-room enforcement

The earlier proposal used a SpaceWeave-specific recurring-author entitlement,
organiser/attendee check-in and consecutive-miss cancellation policy.
[Exchange-led room policy](0036-follow-exchange-room-policy-and-native-check-in.md)
supersedes those independent rules: native policy, eligibility, check-in and
autorelease govern room outcomes.
Requested behaviours without verified native support remain explicit capability
gaps rather than custom application enforcement.
