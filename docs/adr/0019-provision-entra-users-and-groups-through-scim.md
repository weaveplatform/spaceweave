# Provision Entra users and groups through SCIM

Expose an authenticated SCIM 2.0 interface for Entra user and explicitly mapped
group provisioning, including user creation, updates, deactivation, reactivation
and deletion. This makes lifecycle integration a supported provisioning contract
while keeping Workday integration separate and preserving agreed source field
authority. Disabling app access is distinct from deleting a provisioning resource
or erasing retained booking history.
