# Follow Exchange room policy and native check-in

Exchange's supported room policies, native eligibility, check-in and autorelease
are authoritative for managed rooms across SpaceWeave and Outlook; Booking
retains application intentions/local consistency and Exchange owns provider
integration and observed outcomes.
Separate application admission rules, expiry timers or consecutive-miss series
cancellation must not redefine native behaviour; unsupported requested features
remain documented gaps.
This aligns channel outcomes at the cost of native permission, licensing and
integration validation before a capability can be offered.
