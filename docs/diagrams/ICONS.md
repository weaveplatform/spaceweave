# Diagram icon sources

The API component diagram embeds 95 vector icon instances from 43 distinct assets.
The images remain inside the native draw.io source and exported SVG. Viewing the
diagram requires no icon-server requests.

Full-colour illustrations describe application responsibilities. Technology marks
identify the clients, runtimes, providers and protocols named in the architecture.
Labels retain the component purpose and API audience independently of the artwork.

generic pictograms communicate responsibility, such as reception, sensor evidence,
allocation, private background work and floor-plan publication.
